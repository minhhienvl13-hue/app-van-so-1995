# 🔮 App Vận Số Hằng Ngày – Streamlit

Ứng dụng đánh giá vận số theo ngày cho người sinh **01/10/1995 âm lịch – Ất Hợi**.

## Chức năng

- Chọn bất kỳ ngày nào để xem.
- Chuyển đổi dương lịch → âm lịch.
- Hiển thị Can–Chi năm/tháng/ngày.
- Chấm điểm tổng vận.
- Đánh giá:
  - Tài lộc
  - Công việc
  - Tình cảm
  - Gia đạo
  - May mắn
  - Rủi ro
- Hiển thị các dấu hiệu ngũ hành/địa chi.
- Khung giờ thuận tham khảo.
- Bảng xem nhanh 7 ngày.
- Nhóm số "vận may lô đề" chỉ mang tính giải trí/tham khảo, không tuyên bố dự đoán kết quả.

## Chạy trên máy tính

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Đưa lên GitHub + Streamlit Community Cloud

Tạo repository GitHub và tải lên:

- `app.py`
- `requirements.txt`

Sau đó vào Streamlit Community Cloud, chọn repository và đặt:

- Main file: `app.py`

Không cần API key.

## Lưu ý

Đây là ứng dụng tham khảo văn hóa/giải trí. Điểm số và nhóm số không phải kết quả khoa học và không đảm bảo trúng xổ số.
